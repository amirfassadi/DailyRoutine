# DailyRoutine

مربی همراهِ هر روزت — یک اپ وب فارسی برای تمرین، دفتر تصویری غذا و پیگیری عادت‌های روزانه، با پروندهٔ جدا برای هر حساب ChatGPT.

**وضعیت: نمونهٔ آزمایشی قابل توسعه؛ هنوز برای انتشار عمومی به عنوان مربی ورزشی آماده نیست.** این ریپو کد برنامه است؛ عمومی بودن ریپو، اپ میزبانی‌شده یا اطلاعات کاربران را عمومی نمی‌کند.

## امکانات موجود

- تایمر تمرین و استراحت، مکث/ادامه، توقف هنگام خروج از صفحه و راهنمای شماتیک پلانک.
- بررسی آمادگی، خواب، خستگی و علائم؛ تنظیم محدود زمان جلسه بر اساس گزارش‌های ثبت‌شده و پیگیری روز بعد.
- دوربین اختیاری و تحلیل محلی MediaPipe برای هم‌راستایی تقریبی در پلانک معمولی روی دست یا ساعد. حرکات دیگر و تصویر نامطمئن بازخورد «نامشخص» می‌گیرند. فریم‌های دوربین ضبط یا ارسال نمی‌شوند.
- ثبت غذا، مقدار، روغن/شکر و مکمل با عکس اختیاری. عکس فقط با ذخیرهٔ صریح به R2 ارسال می‌شود. کالری و پروتئین فعلاً برآورد دستی‌اند؛ تشخیص خودکار غذا فعال نیست.
- پروفایل بدون اطلاعات پیش‌فرض شخصی، وضعیت روز، تاریخچه، حذف ثبت و خروجی JSON.
- ورود با حساب ChatGPT در محیط Sites و ذخیرهٔ D1/R2 با کنترل مالکیت هر ثبت و عکس.
- ابزارهای MCP فقط برای خواندن دفتر و عکس غذای متعلق به کاربر احراز هویت‌شده. اتصال افزونه در ChatGPT جدا از ورود به سایت است.

## اجرای توسعه

پیش‌نیاز: Node.js >=22.13.0 و pnpm 11.25.0 مطابق package.json.

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm test
pnpm typecheck
pnpm dev
```

اجرای توسعهٔ portable روی پورت 5173 از هویت آزمایشی محلی استفاده می‌کند؛ ورود واقعی ChatGPT توسط میزبان Sites انجام می‌شود. در محیط مدیریت‌شده، پروفایل اجرا و نصب را با helper رسمی Sites تنظیم کنید. اجرا از یک clone تازه روی دستگاه مستقل هنوز بررسی نشده است.

```bash
pnpm build
```

اپ از Vinext/React/TypeScript و Cloudflare Workers استفاده می‌کند؛ دیتابیس D1 است، نه PostgreSQL. تنظیمات binding در `.openai/hosting.json` و مهاجرت‌ها در `drizzle/` قرار دارند. project_id سایت شخصی از این ریپو حذف شده است؛ برای میزبانی از workflow رسمی Sites استفاده و شناسهٔ همان پروژه را تنظیم کنید. صرف `pnpm dev`، D1 را migration نمی‌دهد؛ مهاجرت schema را در runtime انتخاب‌شده اعمال کنید. استقرار روی میزبان دیگری نیازمند جایگزینی مرز احراز هویت است؛ اعتماد مستقیم به هدرهای هویت در یک سرور عمومی امن نیست.

## اعتبارسنجی و محدودیت‌ها

- `pnpm test`: منطق تنظیم جلسه، علائم تأخیری، هندسه/اعتماد تخمین فرم، زمان محلی تهران، احراز هویت و فیلتر مالکیت API با bindingهای mock.
- `pnpm typecheck`: کنترل نوع‌های کد.
- تست‌های mock، صحت واقعی دوربین، اثربخشی پزشکی یا جداسازی کاربران در محیط زنده را ثابت نمی‌کنند.
- مجوز دوربین، بارگیری CDN/مدل، صدا، کیفیت فرم و چرخهٔ واقعی ثبت/خواندن عکس روی گوشی هنوز باید بررسی شوند.
- این نسخه APK نیست. برنامهٔ فعلی نمونهٔ ثابت پلانک برای بزرگسالان است؛ هنوز برنامهٔ مناسب برای هر کاربر را انتخاب نمی‌کند.
- تحلیل در گفت‌وگوی ChatGPT با ابزارهای خواندن ممکن است؛ نوشتن گزارش از چت یا اعمال برنامهٔ پیشنهادی در اپ هنوز پیاده‌سازی نشده است.
